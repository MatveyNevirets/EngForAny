# Студия английского на Ботанике

**Публикация на Netlify:** пошаговая инструкция и готовые настройки репозитория — [NETLIFY.md](NETLIFY.md). Подключайте `engforany2` через Import an existing project; сборка и адаптер Next.js сохраняют работу API формы.

Готовый к показу владельцу одностраничный демосайт на Next.js App Router, TypeScript и обычном CSS. Авторские SVG, локальный шрифт Manrope с кириллицей, без CMS, базы данных, карт-виджетов, аналитики и внешних запросов при отправке формы. **Сайт не опубликован.**

## Запуск

Нужен Node.js 20.9+; проект собран и проверен на Node.js 24.22.0.

```bash
npm install
npm run dev
```

Открыть http://localhost:3000. Production-режим:

```bash
npm run build
npm start
```

Если порт занят уже запущенным экземпляром, сначала остановите его. Для другого порта: `npm run dev -- --port 3001` или `npm start -- --port 3001`.

## Где менять данные

- `src/lib/studio-data.ts`: отдельные разделы `verifiedContacts` (настоящие контакты) и `demoContent` (редакционные примеры), варианты возраста и формата.
- `src/app/globals.css`: дизайн-токены, адаптивная вёрстка и анимации.
- `src/components/illustrations.tsx`: авторская SVG-композиция, иконки и условная схема. Это иллюстрации, а не фотографии студии. Координаты схемы не предназначены для навигации; точный путь открывается в 2ГИС.
- `src/components/interactive.tsx`: мини-урок, переключатель поездки, FAQ, предзаполнение, форма и мобильная кнопка.
- `src/lib/lead-validation.ts`: общие правила клиентской и серверной проверки.
- `src/app/api/leads/route.ts`: единственный API-обработчик `POST /api/leads`.
- `src/lib/send-lead-notification.ts`: серверный адаптер будущей доставки.

Страница в основном серверная; клиентский JavaScript используется для интерактивных блоков. Для анимаций используются CSS и IntersectionObserver. Шрифт поставляется локально пакетом `@fontsource-variable/manrope` (SIL Open Font License); SVG нарисованы для проекта. Motion и генерация растровых изображений не нужны.

## Подтверждённые контакты и допущения

Источник: [карточка 2ГИС](https://2gis.ru/ekaterinburg/firm/70000001117484903), просмотрена 14 ноября 2026 года. Название, адрес и наличие контакта MAX сверены с карточкой. Полный телефон и публичная ссылка MAX взяты из задания; публичная текстовая версия карточки скрывает часть номера.

Адрес: Екатеринбург, Родонитовая улица, 20а, Ботанический. Телефон: +7 (922) 297-19-05. «Около 10 минут пешком / 900 м» — оценка 2ГИС из задания, а не обещание времени в пути.

Допущения для согласования с владельцем:

- Возрастные направления 6–8, 9–12 и 13–16 лет, задания, сценарий знакомства и мини-урок придуманы для презентации. На сайте они помечены «Пример программы».
- Первое знакомство описывает желаемый сценарий, а не подтверждённую услугу. Его длительность, стоимость, содержание и возможность посетить с родителем нужно согласовать.
- Цены, конкретные часы, размер группы и продолжительность курсов не выдуманы и не опубликованы. Взрослое направление известно из названия карточки; его программу предстоит уточнить.
- Возможность онлайн-занятий и занятий по выходным не подтверждена. Блок про дорогу предлагает **обсудить** их до поездки и отмечен «Демоусловия».
- Не добавлялись вымышленные отзывы, преподаватели, регалии, рейтинг или гарантии результатов.
- Нет подтверждённых реквизитов оператора персональных данных и юридических текстов. На демо явно описано отсутствие хранения; это пояснение не заменяет будущие согласие и политику.

## Визуальная запись без API

По запросу пользователя форма работает полностью в браузере. После проверки имени, телефона, возраста, формата и обязательного согласия она показывает «Заявка отправлена. С вами свяжутся!». Сетевых запросов при отправке нет, MAX не вызывается, контактные данные нигде не сохраняются и очищаются после успеха. При ошибке поля остаются заполненными. Это демонстрация интерфейса, не фактическая доставка заявки.

Резервный POST /api/leads и демоадаптер сохранены в исходниках для будущего подключения, но форма их не вызывает. Для текущего сценария токен бота и ID получателя не нужны.

Политика и отдельный текст согласия доступны из формы и футера. Документы содержат явно обозначенные заглушки оператора; перед реальным приёмом заявок потребуется их заменить и согласовать юридические условия. Настройки — src/lib/legal-data.ts.

## Индексация и выпуск

По умолчанию включены `noindex, nofollow` в metadata, заголовок `X-Robots-Tag` и `Disallow: /` в robots.txt. Чтобы выпустить согласованную версию, скопируйте `.env.example` в `.env.local`, задайте реальный `SITE_URL`, замените демонстрационные предложения и только затем установите `ALLOW_INDEXING=true`. **Пересоберите и перезапустите** приложение: metadata и robots генерируются при сборке. OG-изображение и favicon уже предусмотрены.

До публикации владелец подтверждает: оффер, содержание и стоимость знакомства, программы и цены, график, очные/дистанционные форматы, реквизиты, тексты согласия и политики, фактическую доставку заявки. После этого нужны проверка на реальном iPhone с экранной клавиатурой и выпуск на выбранном хостинге. В этой работе публикация не выполняется.

## Проверки

```bash
npm run typecheck
npx playwright install chromium webkit
npm run test:e2e
```

Playwright использует production-сборку (`npm run build` перед запуском), поднимает `npm start`, если сервер ещё не работает. Для отдельного движка: `npm run test:e2e -- --project=chromium-*` или `npm run test:e2e -- --project=webkit-*`.

Матрица и результаты этого запуска записаны в [artifacts/qa/verification.md](artifacts/qa/verification.md); скриншоты главного экрана, блока про дорогу и формы находятся рядом. Chromium: 320, 375, 390, 430, 1440 px. WebKit: предусмотрены 320 и 390 px, но запуск в этой Windows заблокирован политикой управления приложениями (WinError 4551 при загрузке DLL WebKit). Это ограничение среды, **проверка Safari не заявляется пройденной**. Реальный iPhone недоступен.

Тестовый сценарий: программа → предзаполнение → выбор поездки → невалидный телефон → исправление → ошибка сервера без потери данных → повтор → демоуспех; отдельно мини-урок, FAQ, взрослый выбор, reduced motion, скрытие мобильной кнопки, отсутствие горизонтального скролла во всех секциях, отсутствие ошибок JavaScript. API проверяется отдельно: корректная нормализация, недопустимые значения, honeypot, превышение размера, чужой Origin, повреждённый JSON, неверный Content-Type, noindex и OG.
